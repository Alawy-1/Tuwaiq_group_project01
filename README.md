# Block Partitions

The idea of the project is to send arguments to main as a command line that accepts three arguments (argv[0], argv[1], argv[2]), otherwise it will exit the program. 
Argument 1 is the command name, and argument 2 is the file name, while argument 3 is the partitions. 

## Important Note 
Need linux system to run program.

## Usage
1. Compile and run
2. ./program filename Number_of_partition
